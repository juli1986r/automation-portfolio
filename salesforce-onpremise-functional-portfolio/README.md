🚀Caso de Éxito – Salesforce Sales Cloud (Leads y Oportunidades) 🚀
Integración con Sistemas On-Premise
1🚀Relevamiento de Requerimiento🚀
El relevamiento funcional se realizó a partir de reuniones con usuarios del área comercial y referentes de negocio, con el objetivo de comprender el funcionamiento actual del proceso de gestión de Leads y su conversión a Oportunidades.
Durante las entrevistas se identificó que los Leads ingresan a la organización a través de múltiples canales (formularios web, carga manual y sistema on-premise), sin un criterio uniforme de validación ni calificación inicial.
Los usuarios manifestaron dificultades para identificar el estado real de cada Lead, así como inconsistencias en la información disponible al momento de la conversión a Oportunidad.

2🚀Situación Actual Relevada🚀
A partir del relevamiento se detectó que:
No existe una definición clara de qué condiciones debe cumplir un Lead para ser considerado calificado.
La conversión de Leads a Oportunidades se realiza de forma manual y con criterios variables según el usuario.
Se generan duplicidades de información entre Salesforce y el sistema on-premise.
El pipeline de oportunidades no refleja de manera confiable el estado comercial real.
Estas situaciones generan reprocesos, errores operativos y falta de trazabilidad del proceso comercial.
3🚀Necesidades del Negocio Identificadas🚀
Durante el relevamiento, el negocio expresó las siguientes necesidades funcionales:
Contar con criterios claros y documentados para la calificación de Leads.
Estandarizar el proceso de conversión de Lead a Cuenta, Contacto y Oportunidad.
Garantizar la validación de datos contra el sistema on-premise antes de la conversión.
Mejorar la visibilidad del pipeline comercial y el estado de las oportunidades.
Estas necesidades fueron validadas con los stakeholders como prioritarias para la solución.

4🚀Alcance Funcional Definido en el Relevamiento🚀
En función de lo relevado, se acordó incluir dentro del alcance funcional:
Gestión del ciclo de vida del Lead en Salesforce.
Definición de reglas de calificación de Leads.
Conversión controlada de Leads a Oportunidades.
Validaciones e integraciones con sistema on-premise.
Quedaron fuera del alcance funcionalidades relacionadas con campañas de marketing y reporting avanzado.

5🚀Durante el relevamiento se acordó que🚀Acuerdo
Las reglas de negocio deben quedar explícitamente documentadas para evitar interpretaciones.
Los escenarios de error y excepciones deben ser contemplados desde la especificación funcional.
La documentación generada debe servir como insumo para desarrollo, QA y pruebas de aceptación.
Estas consideraciones fueron incorporadas como lineamientos para las siguientes etapas del proyecto.
